# 四轨音游框架

直接打开项目，使用顶部“音游 → 导入 PhiEdit 谱面…”菜单。
选择 RPE JSON 和配套音频，点击“导入并运行”即可测试；再次导入同一份 JSON 会更新原曲目。

详细步骤见上一级文件夹的《开始使用.md》。无需手动挂组件、制作预制体或在脚本里填写曲目路径。

固定四轨 A/S/D/F，只支持 Tap、Hold 和同时按键。支持变 BPM、音乐偏移、暂停、重试、连击和 60% 及格线。默认没有内置谱面。

Unity 版本：2022.3.62f3c1。JSON 依赖：com.unity.nuget.newtonsoft-json 3.2.1。
Windows 为本次已验证的平台。
